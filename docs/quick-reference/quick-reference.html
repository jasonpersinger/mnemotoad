Quick reference, version 0.2.1
Open from the command palette:
MNEMOTOAD: Open PATCHBOOK
MNEMOTOAD: Open MOTIF
MNEMOTOAD: Open CANVAS
  1. 1

    Keep the sound

    PATCHBOOK: Instruments, then New record and Save record. Add a patch and choose its instrument.

  2. 2

    Write the phrase

    MOTIF: New motif. Link a patch under PATCHBOOK context, draw notes, Play motif, Save motif.

  3. 3

    Arrange the piece

    CANVAS: New composition, Add lane, Place motif with repetitions, then Compile and Play arrangement.

  4. 4

    Take it to your DAW

    Export MIDI from MOTIF or Export arrangement MIDI from CANVAS. Each export is a new file in your vault.

MOTIFwith the editor focused

  • Click empty gridDraw a note
  • Drag note / right edgeMove / resize
  • ShiftclickAdd to the selection
  • ShiftwheelScroll through time
  • CtrlwheelZoom
  • ←→Nudge one grid step
  • ↑↓Nudge one semitone
  • Ctrl/⌘+ASelect every note
  • DeleteRemove selected notes
  • EscClear the selection
  • Ctrl/⌘+ZUndo
  • Ctrl/⌘+YRedo (or Ctrl/⌘ Shift Z)
  • Ctrl/⌘+SSave motif

Nudging works with the roll focused; elsewhere in the editor the arrow keys step between notes. The note inspector edits position, pitch, duration and velocity exactly.

CANVAStimeline or clip focused

  • ←→Move one grid step
  • Ctrl/⌘+DDuplicate the clip
  • DeleteDelete the clip
  • []Previous / next section
  • ,.Previous / next marker
  • EscClear the selection
  • Ctrl/⌘+ZUndo
  • Ctrl/⌘+YRedo (or Ctrl/⌘ Shift Z)
  • Ctrl/⌘+SSave composition

Select a clip to set its exact bar:beat:tick position, repetitions and lane. Sections and markers organise the timeline; they never change the MIDI.

Good to know

Source review required
A saved motif changed. Choose Review changed sources, acknowledge, then compile again. Arrangements never change silently.
Saving is protected
If a note changed elsewhere, Save is blocked and your edits stay open. In PATCHBOOK, Ctrl/⌘+S saves the record you are editing.
Recovery register
Drafts and pre-save backups live in MNEMOBARD/Recovery. Inspecting writes nothing; loading asks first and saves nothing.
MIDI
Notes with one tempo and meter. Compositions use 960 PPQ. Imports up to 2 MiB. In REAPER, tick Expand MIDI tracks and Import MIDI tempo map.
Audition
Plain sine tones for checking ideas. No plugins are hosted and no audio is rendered.
